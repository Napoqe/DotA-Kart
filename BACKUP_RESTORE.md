# DotA Kart backup

Snapshot: 2026-10-26.

Clone with GitHub Desktop and install Git LFS. Run `git lfs pull` if large assets are pointers. Copy this repository's `content/` into `content/dota_addons/dota_kart/` and `game/` into `game/dota_addons/dota_kart/` inside Dota 2. Source files, editable models, work files, maps and compiled game resources are included. The manifest lists the current snapshot files and SHA-256 hashes; additional legacy files were retained. Regenerable editor caches and Python bytecode are excluded.
